Analogi Kehidupan Sehari-hari

Koki Hebat Menulis Resep Dulu

Bayangkan kamu ingin menjadi koki hebat. Sebelum memasak, koki profesional menuliskan resep dulu — langkah-langkah yang jelas, terstruktur, dan mudah dipahami siapa pun.

Resep itu bukan makanan, tapi panduan untuk membuat makanan. Kalau resepnya jelas, koki mana pun bisa menghasilkan masakan yang sama enaknya.

💡 Nah, pseudocode itu adalah "resep"-nya programmer. Sebelum menulis kode program sesungguhnya, programmer menuliskan langkah-langkah logikanya dulu dalam pseudocode.

📖 Definisi Pseudocode

Pseudocode (dari kata pseudo = semu/tiruan, dan code = kode) adalah cara menuliskan algoritma yang menyerupai kode program, tetapi tetap menggunakan bahasa manusia yang mudah dibaca dan tidak terikat aturan bahasa pemrograman tertentu.

✨ Ciri-Ciri Pseudocode

1.

Bahasa Manusia

Menggunakan kata-kata yang mudah dipahami.

2.

Sintaks Fleksibel

Tidak ada aturan baku.

3.

Berurutan

Ditulis dari atas ke bawah.

4.

Menggunakan Indentasi

Blok kode menjorok ke dalam.

5.

Universal

Bisa dipahami siapa saja.

6.

Tidak Bisa Dijalankan

Hanya rancangan logika.

Istilah & Struktur Pseudocode

🏗️ Struktur Formal Pseudocode

PROGRAM NamaProgram ← Bagian 1: Identitas
DEKLARASI: ← Bagian 2: Daftar Variabel
variabel : tipe_data
ALGORITMA: ← Bagian 3: Urutan Langkah
[langkah-langkah]
END PROGRAM

PROGRAM

Judul program.

DEKLARASI

Daftar variabel & tipe datanya.

ALGORITMA

Urutan langkah. Inti logika.

📚 Istilah Perintah Umum

NoKata KunciFungsi
1INPUT / READMembaca data dari pengguna
2PRINT / OUTPUTMenampilkan hasil ke layar
3SET / ←Memberi nilai ke variabel
4IF - ELSEPercabangan kondisi
5WHILE / FORPerulangan langkah

💡 Contoh Penggunaan Setiap Istilah

INPUT / READ

READ jumlah_siswa

PRINT / OUTPUT

PRINT "Data tersimpan!"
PRINT jumlah_siswa

SET / ← (Assignment)

total ← 0
total ← total + 100

IF - ELSE

IF suhu > 30 THEN
PRINT "Cuaca Panas"
ELSE
PRINT "Cuaca Sejuk"
ENDIF

WHILE / FOR

FOR i ← 1 TO 5 DO
PRINT i
ENDFOR

⚠️ Penting: Beda ← (Assignment) dan = (Perbandingan)

← (Assignment / SET)

Artinya: "Isi variabel dengan nilai ini."

total ← 100

= (Perbandingan)

Artinya: "Apakah nilainya sama?"

IF status = "Aktif" THEN

Variabel & Tipe Data

Apa itu Variabel?

Variabel adalah "wadah" untuk menyimpan data yang bisa berubah nilainya selama program berjalan. Setiap variabel punya nama dan tipe data.

💡 Analogi: Variabel itu seperti toples di dapur. Setiap toples punya label dan isi berbeda.

📝 Aturan Penamaan Variabel

✅ Yang BENAR

  • • nilai_ujian
  • • totalBelanja
  • • umur, nama_siswa

❌ Yang SALAH

  • • 2nilai (diawali angka)
  • • nilai ujian (pakai spasi)
  • • print, if (kata kunci)

📦 Tabel Tipe Data Dasar

NoTipe DataKeteranganContoh
1intBilangan bulat10, -5, 100
2float / doubleBilangan desimal3.14, 75.5
3char1 karakter tunggal'A', 'Z', '#'
4stringTeks / kalimat"Lulus", "Budi"

💡 Contoh Deklarasi Lengkap

PROGRAM HitungDiskon
DEKLARASI:
total_belanja : int // bilangan bulat
persen_diskon : float // desimal
nama_pelanggan : string // teks
kategori : char // 1 karakter
ALGORITMA:
persen_diskon ← 0.1
READ total_belanja
END PROGRAM

Kontrol Alur Program

Ada 3 jenis kontrol alur utama: Berurutan, Percabangan, dan Perulangan.

1. Percabangan (IF - ELSE)

PROGRAM CekGanjilGenap
DEKLARASI: N : int
ALGORITMA:
READ N
IF N MOD 2 = 0 THEN
PRINT "GENAP"
ELSE
PRINT "GANJIL"
ENDIF
END PROGRAM

2. Percabangan Bertingkat (Nested IF)

PROGRAM KategoriNilai
DEKLARASI: nilai : int
ALGORITMA:
READ nilai
IF nilai ≥ 85 THEN
PRINT "A"
ELSE IF nilai ≥ 70 THEN
PRINT "B"
ELSE
PRINT "C"
ENDIF
END PROGRAM

3. Perulangan FOR (Jumlah Pasti)

PROGRAM Cetak1SampaiN
DEKLARASI: N, i : int
ALGORITMA:
READ N
FOR i ← 1 TO N DO
PRINT i
ENDFOR
END PROGRAM

4. Perulangan WHILE (Kondisi)

PROGRAM TotalBelanja
DEKLARASI: harga, total : int
ALGORITMA:
total ← 0
READ harga
WHILE harga ≠ 0 DO
total ← total + harga
READ harga
ENDWHILE
PRINT "Total: ", total
END PROGRAM

Rangkuman Poin Penting

1. Apa itu Pseudocode?

Kode semu yang menyerupai program, mudah dibaca manusia, dan berfungsi sebagai "cetak biru" sebelum menulis kode nyata.

2. Mengapa Pakai Pseudocode?

Fokus ke logika, mudah dikomunikasikan, bisa jadi bahasa apa pun.

3. Istilah Penting

READ/WRITE · IF-ELSE · FOR/WHILE

Setelah menonton: Diskusikan dengan teman sebangku — apa perbedaan paling mencolok antara pseudocode dengan bahasa pemrograman?
