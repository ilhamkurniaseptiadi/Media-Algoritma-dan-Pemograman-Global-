Pseudocode

Pseudocode adalah cara menuliskan algoritma yang menyerupai kode program, tapi tetap mudah dibaca manusia dan tidak terikat sintaks bahasa tertentu.

Kata Kunci Pseudocode

PROGRAM

Nama program

DEKLARASI

Deklarasi variabel

INPUT

Baca data

OUTPUT

Tampilkan hasil

IF/ELSE

Percabangan

FOR

Loop diketahui

WHILE

Loop belum pasti

MOD

Sisa bagi

Contoh 1 — Cek Ganjil/Genap

PROGRAM CekGanjilGenap
DEKLARASI:
N, sisa : integer
ALGORITMA:
INPUT N
sisa ← N MOD 2
IF sisa = 0 THEN
OUTPUT "GENAP"
ELSE
OUTPUT "GANJIL"
ENDIF
END PROGRAM

Contoh 2 — Kategori Nilai (Nested If)

PROGRAM KategoriNilai
DEKLARASI:
nilai : integer
ALGORITMA:
INPUT nilai
IF nilai >= 85 THEN
OUTPUT "A"
ELSE IF nilai >= 70 THEN
OUTPUT "B"
ELSE IF nilai >= 60 THEN
OUTPUT "C"
ELSE
OUTPUT "D"
ENDIF
END PROGRAM

Contoh 3 — Perulangan FOR: Cetak 1 sampai N

PROGRAM Cetak1SampaiN
DEKLARASI:
N, i : integer
ALGORITMA:
INPUT N
FOR i ← 1 TO N DO
OUTPUT i
ENDFOR
END PROGRAM

Contoh 4 — Perulangan WHILE: Total Belanja

PROGRAM TotalBelanja
DEKLARASI:
harga, total : integer
ALGORITMA:
total ← 0
INPUT harga
WHILE harga ≠ 0 DO
total ← total + harga
INPUT harga
ENDWHILE
OUTPUT total
END PROGRAM

Contoh 3 — Cetak 1 sampai N (Loop)

N = int(input("Masukkan N: "))
for i in range(1, N + 1):
print(i)

range(1, N+1) menghasilkan 1 sampai N. Ingat: Python berhenti di N, bukan N+1.
