Apa itu IDE dan Mengapa Kita Membutuhkannya?

Pernahkah kamu bertanya: "Mengapa programmer tidak menulis kode di Microsoft Word atau Notepad biasa saja?" Mari kita pahami dengan analogi dapur!

IDE (Visual Studio Code)

Ibarat Dapur Chef Bintang Lima

IDE (Integrated Development Environment) adalah lingkungan terpadu. Semua alat programmer sudah berkumpul di satu meja kerja: editor teks cerdas, terminal eksekusi, pendeteksi error, hingga pengatur file.

✅ Warna-warni kode otomatis memudahkan membaca logika
✅ Terminal langsung terintegrasi di layar yang sama
✅ IntelliSense: asisten yang melengkapi kode otomatis

Mengapa Visual Studio Code Pilihan Utama Dunia?

1. Ringan & Gratis

Dikembangkan oleh Microsoft secara open-source. Gratis digunakan di Windows, Mac, maupun Linux tanpa lisensi berbayar.

2. Ekosistem Raksasa

Memiliki puluhan ribu ekstensi. Hari ini belajar Python, besok membuat web HTML/CSS, semuanya cukup di satu aplikasi.

3. Keterampilan Nyata

Digunakan oleh lebih dari 70% software engineer profesional di seluruh dunia. Apa yang kamu pelajari di SMAN 9 langsung terpakai di industri.

Menghubungkan VS Code & Python

Mengapa Kita Wajib Memasang Ekstensi Python?

Secara bawaan pabrik, VS Code adalah aplikasi universal yang belum tahu aturan tata bahasa Python. Memasang ekstensi Python ibarat memasangkan kacamata pintar dan kamus bahasa bagi VS Code.

1. Tombol 'Run' Segitiga Hijau

Memunculkan tombol segitiga di kanan atas editor. Cukup 1 klik, kodemu langsung dieksekusi di terminal otomatis tanpa repot mengetik perintah manual.

Asisten pintar yang melengkapi kodenya otomatis. Saat kamu baru mengetik pr, VS Code langsung menyarankan print() sehingga kamu tidak lelah mengetik.

3. Linter (Deteksi Cacat Kode)

Memberikan garis bawah merah bergelombang saat kamu lupa tanda kurung atau salah ketik, memberi tahu di mana letak salahnya sebelum program dijalankan!

Mulai Menulis Baris Kode

Program Python Pertama: Perintah Print & Variabel

Menulis kode pemrograman sebenarnya mirip seperti memberikan instruksi kepada asisten robot yang sangat patuh. Mari kita pelajari 2 mantra sakti pertama: mencetak kalimat dan menyimpan data dalam toples (variabel).

1. Mantra Pencetak Teks: print()

Perintah print() berfungsi untuk menampilkan tulisan atau angka ke layar Terminal.

# 1. Mencetak Teks Huruf (Wajib pakai tanda kutip)
print("Halo, SMAN 9 Yogyakarta!")

# Output di Terminal:
>> Halo, SMAN 9 Yogyakarta!
# 2. Mencetak Perhitungan Angka (Tanpa kutip)
print(10 + 5)

# Output di Terminal:
>> 15
Awas Jebakan Pemula:
Jika kamu menulis print("10 + 5") dengan tanda kutip, komputer menganggap itu tulisan biasa, sehingga outputnya adalah 10 + 5. Tapi jika ditulis print(10 + 5) tanpa tanda kutip, komputer akan menghitungnya menjadi 15!

2. Variabel: Wadah / Toples Berlabel untuk Menyimpan Data

Bayangkan kamu punya beberapa toples di meja belajarmu. Kamu memberi label di toples tersebut agar tahu isinya. Di Python, toples itu disebut Variabel!

# Membuat variabel
nama_sekolah = "SMAN 9 Yogyakarta"
jumlah_siswa = 36

# Menampilkan isi variabel menggunakan koma (,)
print("Sekolahku adalah:", nama_sekolah)
print("Kapasitas kelasku ada:", jumlah_siswa, "orang")

Aturan Resmi Menamai Variabel di Python:

  • Hanya boleh memuat huruf, angka, dan garis bawah / underscore (contoh: nama_siswa).
  • Tidak boleh diawali dengan angka (contoh salah: 1nama, contoh benar: nama1).
  • Tidak boleh mengandung spasi (gunakan tanda hubung bawah / snake_case, contoh: nilai_harian).
  • Sensitif huruf besar dan kecil (case-sensitive). Variabel Skor berbeda dengan skor.

File: kalkulator_umur.py Struktur Interaktif Dinamis
# ====================================================
# PROGRAM KALKULATOR SAPAAN DAN UMUR INTERAKTIF
# Menggunakan Fungsi input() & Konversi int()
# ====================================================

print("=== PROGRAM SAPAAN & KALKULATOR UMUR INTERAKTIF ===")

# 1. Mengambil masukan interaktif dari pengguna (Keyboard)
nama = input("Siapa nama lengkapmu? ")
perasaan = input("Bagaimana kabarmu hari ini? ")
tahun_lahir = int(input("Tahun berapa kamu lahir? "))

# 2. Melakukan kalkulasi usia menggunakan tahun saat ini (2026)
tahun_sekarang = 2026
usia = tahun_sekarang - tahun_lahir

# 3. Menampilkan hasil interaksi yang terformat
print(" ================ HASIL ANALISIS ================")
print("Halo,", nama, "! Senang mengetahui perasaanmu hari ini:", perasaan)
print("Di tahun", tahun_sekarang, "ini, usiamu adalah:", usia, "tahun.")
💡 Mengapa Memakai input(): Fungsi input() membuat program berhenti sejenak dan menunggu pengguna mengetikkan teks di terminal, lalu menyimpannya ke dalam variabel.
💡 Mengapa Wajib int(input()): Semua data dari keyboard dibaca sebagai teks (str). Untuk bisa dikurangkan dalam matematika (2026 - tahun_lahir), data teks harus diubah menjadi integer dengan pembungkus int(...).
Tantangan Modifikasi & Variabel Baru (Pioneer):
  1. Tambahkan satu variabel input baru untuk menanyakan tahun target masa depan, misalnya:
    tahun_target = int(input("Di tahun berapa kamu berencana lulus kuliah/sukses? "))
  2. Lakukan kalkulasi usia siswa pada tahun target tersebut:
    usia_target = tahun_target - tahun_lahir
  3. Cetak pesan masa depan yang memotivasi di akhir program, misalnya:
    print("Di tahun", tahun_target, "kamu akan berusia", usia_target, "tahun dan siap meraih impian!")

Studi Kasus Voyager: Sistem Penilaian Kelulusan Tugas Otomatis

Problem Solving Code — Mengeksplorasi logika percabangan kondisional (if-else), validasi data input, dan pemecahan masalah mandiri di VS Code PC Lab.

Skenario Studi Kasus Lab:

Sebagai seorang software developer muda di sekolah, kamu diminta merancang sebuah skrip otomasi bernama penilaian_tugas.py di VS Code. Program ini bertugas memproses input nilai tugas siswa dan secara otomatis menentukan apakah siswa telah mencapai Kriteria Ketercapaian Tujuan Pembelajaran (KKTP) atau memerlukan pendampingan remidial.

Spesifikasi Persyaratan Teknis Program:
  • Masukan Dinamis: Program meminta masukan Nama Siswa (input), Mata Pelajaran (input), dan Nilai Angka Tugas (float(input(...)) atau int(input(...))).
  • Batas Kriteria Ketuntasan (KKTP): Nilai ambang batas kelulusan tugas adalah 75.
  • Kondisi Tuntas (Nilai >= 75): Program mencetak status [STATUS: LULUS / TERCAPAI] dan memberikan ucapan selamat serta motivasi mempertahankan prestasi.
  • Kondisi Belum Tuntas (Nilai < 75): Program mencetak status [STATUS: PERLU PENDAMPINGAN / REMIDIAL], menghitung selisih kekurangan poin (selisih = 75 - nilai), dan memberikan pesan konstruktif berapa poin lagi yang harus dicapai.
Arsitektur Alur Algoritma (Panduan Perancangan):
1. START
2. Input nama_siswa, mata_pelajaran, nilai
3. Tentukan kktp = 75
4. IF nilai >= kktp THEN:
      Cetak "Selamat! Anda dinyatakan LULUS"
   ELSE:
      Hitung selisih = kktp - nilai
      Cetak "Status REMIDIAL, Anda butuh", selisih, "poin lagi"
5. END

*Ingat: Gunakan indentasi (tekan Tab atau 4 spasi) pada baris perintah yang berada di dalam blok if dan else!

Tantangan Ekstra Voyager (Multi-Kondisi & Validasi):

Kembangkan logika programmu menggunakan struktur if - elif - else untuk mencetak predikat huruf:

Nilai >= 90 : Predikat A
Nilai >= 75 : Predikat B
Nilai < 75 : Predikat C

Buka Spreadsheet Guru > Extensions > Apps Script, lalu tempel kode berikut dan Deploy as Web App (Access: Anyone):

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date(),
      data.nama,
      data.kelas,
      data.absen,
      data.skor,
      data.kategori,
      JSON.stringify(data.detail)
    ]);
    return ContentService.createTextOutput(JSON.stringify({"status":"success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"status":"error","message":err}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
